# nurse-support-tools
看護師のシフトを組むプログラムです
nurse-support-tools
看護業務の「ちょっと大変」を解決するための、ローカル完結型支援ツール集

このリポジトリは、現役の看護師が現場の効率化を目指して作成したツール群です。 Python (Streamlit) をベースにしており、**「個人情報保護」と「導入のしやすさ」**を最優先に設計しています。

🚀 収録ツール
現在、以下の3つのツールを同梱しています。各ツールは異なるポートで同時に動かすことが可能です。

シフト管理システム (:8501)

複雑な勤務交代やメンバー構成を視覚的に管理します。

退院支援マネジメント (:8502)

退院調整に必要な情報を整理し、共有をスムーズにします。

アルコールカウント (:8503)

薬剤や手指消毒の在庫・使用量を簡単に算出・記録します。

🛡️ セキュリティとプライバシー（管理者の方へ）
本ツールは、医療現場での利用を想定し、以下のセキュリティポリシーで動作します。

完全オフライン動作: インターネットへのデータ送信は一切行いません。

ローカル保存: 入力されたデータは、使用しているPCのブラウザ（Local Storage）にのみ保存されます。サーバーやクラウドへの蓄積は行われません。

インストール不要: システムファイルを書き換えないため、不要になったらフォルダごと削除するだけでPCを元の状態に保てます。

⚙️ 使い方（開発者・利用者向け）
1. 実行方法
dist フォルダ内の run_app.exe をダブルクリックして起動してください。 自動的にブラウザが立ち上がり、ツールが表示されます。

2. ソースから実行する場合
Bash
pip install streamlit pandas jpholiday
streamlit run app.py
